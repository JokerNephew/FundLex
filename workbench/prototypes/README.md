# FundLex 大批量合同工作台原型

打开 `bulk-contract-workbench.html` 即可体验，不依赖 API 或模型。

- **任务总览**：查看四季度合同条款核验示例任务。
- **批量导入**：载入 368 份可接收文件和 3 份异常示例，或选择本地文件体验检查；支持追加、搜索、筛选、移除和分页。
- **处理进度**：查看整个任务的总进度和逐合同状态，体验任务暂停、继续与模拟推进。
- **合同结果**：在任务全部 368 份示例合同中搜索和筛选，查看证据详情，下载示例汇总和逐合同报告。

文件选择只读取名称与大小，不读取合同内容。页面不上传文件、不调用模型。所有记录、统计及下载内容均为虚构示例。22 个业务动作的自动写入仍关闭，原型不提供最终合同下载。

产品诊断、信息架构与正式实现的后端缺口见 `docs/BULK_WORKBENCH_PROTOTYPE_DESIGN.md`；验证记录见 `docs/BULK_WORKBENCH_PROTOTYPE_VALIDATION.md`。
