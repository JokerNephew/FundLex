**台阶纪律（每阶均适用）**：
1. 同波内分 20~50 份子批，子批标签先冻结后跑批；新缺陷修复后**同波回归**，不带病扩样。
2. 边界单列：不可解析/受保护/零目标合同按第一波 boundary 口径单列、保留分母口径（FL-D670 先例）。
3. 历史留史：每波独立成册三轮并排式呈现（r1/r2/r3 口径），绝不覆盖。
4. 不留出稀释：开发波与留出波分开统计；若据留出调优，该批转回归材料、不再称独立验收（10-29 口径）。

## 3. 资源与运维测算（第一波实测外推，仅量级）

- 单合同账本：r3 均值 ≈ $0.265/份·次、21 次调用、4.6 min → 100 份 ≈ $26.5 / 2100 调用 / 7.7 小时（串行）；500 份 ≈ $130 / 5 万调用 / 38 小时（并发与限流方案另列，FL-D445 不设费用门槛）。
- 长跑建制（r2 批死+r3 看门狗失明双教训）：运行时背景机制 + setsid + PYTHONUNBUFFERED=1 + **修复版看门狗**（模式外置文件+python 锚定+发车 60s 阴检）+ 批死 15 分钟自报。
- FL-D985 资源项（recall_run gateway close）为 W2 起跑前**必办**——500 份量级的 fd/连接累积将致命。

## 4. 观测项并入（每波报告固定段）

- **G14 MISS_TARGET_RESOLUTION**（EN1 B8 判据到位前按本口径）：每案 G14 未决数、`verified site missing` 计数、与上波差分。
