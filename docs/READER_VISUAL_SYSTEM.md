# FundLex 合同阅读器视觉规范

适用范围：生产 V1 的「合同修订审查」弹窗、「合同比对」Word 视图、双栏对照视图。  
本次只统一阅读器内部的视觉语言，不改变合同修订、接受/拒绝、采用 A/B、生成与下载逻辑。

## 1. 设计定位

- B 端法务/合规工具，优先信息密度、可读性和长时间阅读舒适度。
- 阅读器使用稳重的灰蓝主色；工作台、任务表格、表单继续沿用原有品牌色。
- 修订语义优先于装饰：红删、绿增、橙改和高亮必须清楚，不被卡片或按钮样式盖住。
- 动效只保留状态反馈，不做装饰性动画。

## 2. 色彩 token

统一定义在 `frontend/app.css` 的 `:root`，以 `--fx-` 前缀复用：

| 用途 | Token | 值 |
| --- | --- | --- |
| 阅读器主色 | `--fx-primary` | `#2f5b83` |
| 主色深色 | `--fx-primary-strong` | `#244866` |
| 主色浅底 | `--fx-primary-soft` | `#eef4fa` |
| 主文字 | `--fx-ink` | `#1f2933` |
| 次文字 | `--fx-muted` | `#667380` |
| 分割线 | `--fx-line` / `--fx-line-soft` | `#d7dee5` / `#eaeef2` |
| 阅读画布 | `--fx-canvas` | `#f1f4f7` |
| 删除 | `--fx-diff-del` / `--fx-diff-del-bg` | `#9d4a43` / `#fbefee` |
| 新增 | `--fx-diff-ins` / `--fx-diff-ins-bg` | `#2f6b4f` / `#edf6f0` |
| 修改 | `--fx-diff-mod` / `--fx-diff-mod-bg` | `#87631f` / `#fdf5e3` |
| 当前定位 | `--fx-focus` / `--fx-focus-bg` | `#b07a24` / `#fff3d5` |

- 删除/新增只使用低饱和底色 + 删除线/下划线，不使用大面积高饱和填充。
- Word 视图保持 Word 的红色作者修订语义：插入下划线、删除删除线、段落左侧红色变更条；颜色统一降低到 `#9d4a43` 一档。
- 双栏视图使用同样的删除/新增/修改底色；当前定位统一用浅琥珀底和 `#c08a2e` 轮廓。
- 当前页签、选中修订、按钮主操作统一使用灰蓝，不再与修订语义色混用。

## 3. 尺寸与组件

- 圆角：弹窗 `12px`，卡片/面板 `9px`，按钮/输入框/分段控件 `6px`，标签 `4px`。
- 间距：4px 栅格；工具栏内边距 8–12px，面板 12–18px，文档正文 24–44px。
- 按钮高度：阅读器工具按钮 29–30px；主操作 33px；同类批量按钮（全部接受/全部拒绝、全部采用 A/B）保持同一高度和边框。
- 弹窗：桌面四周 20px 留边，移动端 6px；1px 中性边框 + 柔和阴影；背景遮罩 `rgb(15 23 32 / .56)`。
- 分割线只使用 `--fx-line` 或 `--fx-line-soft`；主内容区不再叠加多层阴影。

## 4. 三个阅读器

### 合同修订审查弹窗

- 顶部 17px 文档标题，上方 10px 字距小标题「合同修订审查」；右上角「返回任务」为次要按钮。
- 左侧合同卡片与右侧修订清单使用同一 9px 圆角、同一分割线；顶部工具栏为浅灰底。
- 正文为宋体/衬线阅读字体，15px 左右，行高 2；内容最大宽度 920px 居中，避免超长行。
- 修订清单每张卡：编号、规则号、操作标签、接受勾选；原文灰底，修改后浅绿底。
- 底部「生成选择版合同」为唯一主操作；「返回报告」为次要操作；交付说明与快捷键折叠为一行，默认收起。

### Word 视图

- 左修订栏 300px 左右，中合并稿，右源文档上下分栏。
- 合并稿为纸张式白色页面，最大宽度 800px，浅灰画布承托；源文档默认关闭，按需加载。
- 修订栏每行固定 136px，保证三行预览和「采用 A/B」完整可见；虚拟化行高与 JS 常量保持一致。
- 源文档宽度 360px（1100px 以下 300px），字号小于主文档，保留原文结构。

### 双栏对照

- A/B 卡片头使用相同边框和 9px 圆角，A 用灰蓝徽标，B 用浅琥珀徽标。
- 两栏正文使用同一衬线字体、行高和页边距；右栏使用极浅冷色底做弱区分。
- 中间拖动条使用中性灰，hover/focus 时才显示主色；连线使用灰蓝，当前连线加深。
- 底部人工选择栏：全部采用 A/B、定位待选择为次要按钮；「生成选择结果」为唯一主操作。

## 5. 可读性与可访问性

- 正文行高不低于 1.9；合同正文用衬线字体，UI 标签用无衬线字体。
- 修订标记保留至少 4.5:1 的文字对比度；当前定位用轮廓，不覆盖原文颜色。
- 所有按钮、勾选框、单选框、下拉框保留键盘焦点轮廓；阅读器内焦点颜色改为灰蓝。
- `prefers-reduced-motion` 沿用全局规则。

## 6. 范围与未做项

- 本次改版作用于生产 V1 阅读器；V2 React 页面未做同版视觉改版。
- 不包含深色模式。
- 不改动任何业务字段、接口、接受/拒绝规则、A/B 选择规则、生成与下载逻辑。
