# FundLex 多对多定位与实际产物复核规格

2026-10-14 用户已授权开发。保持既有资格、收费画像、DOCX 编辑器和发布门禁；任何失败均拒绝相关动作。

## 范围解析

每个 action 可以对应多个章节/子节/段落，同一段落可以对应多个 action。先使用既有确定性章节与子节解析；无法解析子节时，在已确定的允许上级章节中，以有界分段上下文调用模型识别承担该业务功能的连续段落。返回原文引文与理由，代码回查唯一来源、所属区域和结构边界。禁止按模型坐标直接写入；禁止整章无约束重写。章节缺失、范围过宽、证据不唯一必须进入例外。

## 目标盘点和固定材料

全部计划基于原始合同形成。确定性目标匹配失败但业务候选存在时允许模型辅助寻找精确原文；每 action 盘点全部候选，不把同规则的多个独立目标视为歧义。单条引文的重复来源仍拒绝。固定文案由代码从规则及已验证收费槽位组装；生成模式仅保留 R01/R02/R10。余文只能逐字来源回查，不允许模型编写；默认精确替换核心引文，核心以外原文由编辑器自然保留。无法明确哪些旧条件应删除时拒绝，并由实际产物复核发现矛盾。跨 action 编辑重叠拒绝所有涉事 action，正文/摘要及同 action 多位置原子一致。

## 实际产物复核

临时生成通过编辑器硬校验的 DOCX；重新读取 final 的实际段落，不把计划文字冒充产物。独立模型接收 action 要求、必要画像、修改前章节、实际修改后对应章节（有界且不得静默截断），逐 requirement 给出 satisfied/unsatisfied/unknown 和可回查引文。还必须核对未丢失余文、无旧条件冲突、全部目标覆盖。生成器的解释不参与复核。

失败或不确定即撤销整个 action，重新从原件生成剩余计划；新组合必须重新复核，旧复核不能授权新 plan 或新 artifact。最多 2 次生成/复核轮次，第二轮失败的动作撤销并安全拒绝剩余交付（不无限循环）。报告绑定原件、最终计划、实际 artifact 哈希及复核证据；未经最终组合复核不能开放修改文件。

## 状态和验收

not_matched/范围或目标未知均进入例外；明确 not_applicable 和 satisfied_no_change 不算例外。保留现有 complete/complete_with_exceptions/incomplete 分级。自动测试覆盖标题变体、无标题、跨业务范围、多目标、多对多、重复引文、非法范围、冲突、实际复核回滚及哈希绑定。真实评测上限提前登记，既有 gold 不改；按已标注应改目标完成率与错误写入计数评价，不以动作执行数代替正确率。

## 进度与归属

核心 agent 顺序完成范围/目标、实际产物复核、集成安全回归。主 agent 负责评测工具、预算与真实运行、发布、部署 4C8G 配置；无并行同文件编辑，无真实模型调用由核心 agent 发起。发布前旧包因引擎/提示变化拒绝正式交付，必须重新证据审计及发布。
