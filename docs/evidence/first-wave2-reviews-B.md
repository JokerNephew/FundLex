## 1. 方法

1. 用 python-docx 按 `document.xml` 中 `w:p` 顺序（含表格内段落）提取源/final 全文，逐段 diff；段号为该顺序的 1-based 序号（与 report.json 的 `pNNN` 编号体系不同）。
2. redline 分别重建两种视图：
   - accept：保留 `w:ins` 文本、丢弃 `w:delText`；
   - reject：保留 `w:delText`、丢弃 `w:ins` 文本。
   再与 final / source 全文逐段精确比较。
3. 检查 final 内 `w:ins`、`w:del`、`w:delText` 均为 0。
4. 校验 `report.output_validation.final_sha256` / `redline_sha256` 与实际文件、`source_sha256` 与源文件。
5. 按指南逐条核对适用性：四份均为 **A/C 两个类别**、**非浮动管理费**（合同中无“超额管理费/或有管理费/浮动”条款）、**C类计提销售服务费**，因此 G02/G04 为 no-op、G19/G20/G21 不适用、G22 适用。
6. 空段按 final 与源的空白段落数差核对，并读取段落 XML 确认确为可显示的空白段（1.5倍行距、24磅）。
