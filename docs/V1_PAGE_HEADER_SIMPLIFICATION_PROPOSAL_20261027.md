## 后续讨论：面包屑移入顶栏（最新建议，优先于下方初稿）

- 用户提出“把面包屑放在顶栏怎么样”。建议采用：**顶栏承载唯一位置导航，内容区承载操作/对象**，而不是将旧面包屑简单上移后继续保留大标题。
- 顶栏：品牌｜面包屑｜通知/账号；面包屑替换原动态业务标题，原内容区面包屑删除。
- 一级页顶栏仅“合同修改 / 合同比对 / 指引生成”等当前入口，不固定添加并列首页“工作台”前缀；内容区不再重复业务大标题、英文眉题、泛化介绍或单列表标题。
- 创建页顶栏为“合同修改 › 新建任务”等；内容直接表单，不再增加“新建修改任务”大标题和同目标返回按钮；业务祖先可点击返回并恢复筛选/分页。
- 详情页顶栏“合同修改 › 任务详情”，内容唯一对象标题为实际任务名；合同审阅顶栏“合同修改 › 所属任务 › 合同审阅”，内容唯一对象标题为实际合同名。路径表达层级，内容表达对象，避免把同一长文件名重复两遍。
- 主操作仍在内容操作行，列表可展示“共N个任务＋新建任务/刷新”，不把业务操作塞入全局账号区；真实统计沿用可靠后端，不引入额外统计卡片。
- 普通列表/创建/支持页由顶栏当前项承担唯一页面主标题语义；对象详情页由内容对象名承担主标题语义。实现时明确导航与heading结构，不因移除重复标题丢失可访问名称/浏览器标签。
- 移动端不能继续沿用隐藏`.topbar-title`的规则而把唯一路径一起隐藏；采用紧凑上级/当前页路径，长名称截断并可获取全文，保证通知/账号入口与正文空间。

## 初稿：内容区唯一页面标题（历史；已由顶栏路径建议调整）

### 1. 顶栏只放全局功能

- 左侧品牌入口，右侧通知、身份与账号操作；删除动态业务标题，不拿另一句标语填空。
- 页面身份由内容主标题提供；浏览器标签 `document.title` 随当前业务/对象变化，不能因删除顶栏文字而丢失可访问名称。
- 不同时在顶栏和内容区放两套面包屑。

### 2. 侧栏只负责跨业务导航

- 继续保留工作台、合同修改、合同比对、指引生成、修改指引、飞书绑定及管理员入口。
- 当前业务的高亮属于必要导航反馈，不视为需要删除的重复内容。
- 工作台是并列入口，不再在所有业务页面重复写成“工作台›某业务”的固定前缀。

### 3. 一级页面保留一个内容标题

- 工作台、三个业务列表、修改指引、飞书绑定、用户管理均无面包屑、无英文眉题、无重复标题卡片。
- 唯一主标题在同一条水平基线，右侧放一个页面主操作。
- 标题下面直接进入统计/筛选/列表；单一列表无需再套一个“修改任务”标题行。
- 同一页面只保留一个常驻新建按钮，去掉“新建合同修改/新建批量任务”的双重入口和称谓差异。

```text
FundLex                                      消息  账号
──────────────────────────────────────────────────────
侧栏     合同修改                        ＋ 新建修改任务
         搜索任务    状态    指引    排序    刷新
         ┌───────────────────────────────────────┐
         │ 任务名称  合同份数  进度  状态  更新时间 │
         └───────────────────────────────────────┘
```

三业务标题/操作配对：合同修改—新建修改任务；合同比对—新建比对任务；指引生成—新建生成任务。白卡片只承载筛选与数据，不重复业务名称。

### 4. 子页面只给上级路径，不复述当前页

| 页面 | 弱化的上级导航 | 唯一主标题 |
|---|---|---|
| 新建修改 | ← 合同修改 | 新建修改任务 |
| 新建比对 | ← 合同比对 | 新建比对任务 |
| 新建生成 | ← 指引生成 | 新建生成任务 |
| 业务任务详情 | ← 对应业务列表 | 实际任务名称 |
| 单合同结果/审阅 | 合同修改 › 实际所属任务（均可返回） | 实际合同文件名 |

- 上级导航不再把当前标题作为末级重复一遍；不另加一个同目标“返回任务列表”按钮。
- 上级链接恢复原列表筛选、分页及任务上下文；不能用浏览器back代替明确父级，因为深链可能从外部直接进入。
- 详情页主标题右侧放状态和必要操作；下方用元信息行展示进度、时间、版本，不再使用“任务详情”泛称覆盖对象名称。
- 长名称按断点合理换行/截断且可获取完整名称，不能挤压主操作或造成横向溢出。
- 审阅/比对页使用紧凑对象标题和操作行，保留右侧差异栏；需要固定标题时固定原有这一行，不再新增重复标题。

### 5. 说明文字按使用场景安置

- 删除业务列表页“跟踪进度、查看结果”等泛化介绍；首次使用说明放空状态或可收起帮助，不长期占据页首。
- 文件格式、大小限制放上传区；A原版→B对比版方向放文件选择/阅读器标签附近。
- 生成候选不是已启用指引、需人工审阅/导入的边界保留在新建确认区及候选结果区，列表可用紧凑提示或帮助入口说明；**去冗余不能去掉安全告知**。
- 预算、费用、范围、权限、失败原因等影响决策的信息不因精简而隐藏或取消。
