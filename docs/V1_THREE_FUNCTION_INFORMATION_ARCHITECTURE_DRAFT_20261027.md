## 三、工作台（重构原任务总览）

1. 上方行动区：显著的“新建合同修改”主入口，旁边并列“新建合同比对”“生成修改指引”；不再整屏只介绍批量修改。
2. 第二行任务指标：进行中、需要处理、近期完成，均按任务数统计并可点击筛选。具体时间窗口明确；不把合同份数、比对组数、法规份数相加。
3. 主区“我的任务”：全部/合同修改/合同比对/指引生成标签，支持关键词/状态/日期/排序。列为任务名、类型、业务规模（分别为份/组/法规）、当前阶段、需要处理的事项、更新时间、进入操作。
4. 完成与可交付分开：后台结束不等于可下载最终合同；生成结束不等于候选已批准或修改指引已启用。
5. 仅在有明确数据依据时显示需补传/需处理失败/需选择差异/候选待审阅等行动项。新账号用三入口与简明说明，不展示虚假的成功率。

## 四、各业务子页面

### 合同修改（第一优先级）

`修改任务列表 → 新建修改任务 → 修改任务详情 → 单合同结果/修订审阅`

- 列表：模块标题+新建按钮；搜索筛选+列表，不复制工作台全部统计。
- 新建：左侧任务名、DOCX上传、文件清单，右侧当前修改指引只读摘要、提交检查和主按钮。不新增指引上传/切换入口。
- 详情：任务名/处理阶段/真实计数、异常与暂停原因、合同明细及批量下载；指引版本作为任务快照可追溯。
- 单合同：独立可深链结果页；正文与右侧修订审阅、实际可用下载、未完成事项。报告证据保留二级入口，长文操作不只放在浮层。

### 合同比对

`比对任务列表 → 新建比对任务 → 比对详情/阅读器`

- 不再把任务列表、创建表单和结果长距离堆在一页。
- 新建保留当前统一样式、左右文件卡片与批量配对。
- 阅读器以正文为主，顶部紧凑合同组切换，左/中为两份正文，右侧固定宽度独立差异栏；选择/生成/下载集中，覆盖警告不能隐藏。
- 窄屏单侧正文切换、差异入口易达；选中项/滚动/返回筛选状态可恢复。

### 指引生成

`生成任务列表 → 新建生成任务 → 生成任务详情/候选指引工作区`

- 新建：上传 DOCX 或带文本层 PDF 法规；说明输入、参考合同语料快照、输出是候选指引；高级参数折叠，不暴露服务器路径或模型调试项。
- 运行中默认进度总览：把底层步骤映射为法规读取、要求提取、合同影响分析、起草、核验与补漏、候选输出；不制造精确百分比。
- 结果工作区收敛为五个局部标签：总览、候选指引、法规依据、待处理问题、版本与导出。Quality/Coverage/Residual 不继续作为八个英文平级导航，按业务解释归入问题与证据视图；关键发布门禁仍显式展示。
- 候选指引采用条目目录/内容编辑/证据查看；支持人工编辑、版本对照和按当前版本审批/发布。发布版本不可静默改写。
- 清楚展示“候选已发布”“尚未导入修改引擎”“当前是否启用”，没有对应能力/接口时不提供假按钮。

### 修改指引与支持页面

- 修改指引：当前启用版本、指引库、上传/解析/核验/启用、历史；不承担法规生成任务。
- 飞书绑定继续独立且只做绑定；账号密码/退出在右上角；管理员页面只对管理员显示。

## 五、跨功能关系

- 三业务都能独立创建，不把指引生成设为合同修改必经步骤。
- 生成结果可经显式导入、核验和启用流程成为修改资源，不能因候选发布自动改变当前指引。现有边界未打通时，先保留受控导出/上传核验流程；一键导入是后续能力，不能假设已实现。
- 修改结果可提供“与原件比对”的预填入口，仍需用户确认后创建独立比对任务；若需服务端复用文件，必须补来源关联和 owner 校验接口，不暗中自动提交或付费运行。

## 六、视觉、导航和数据原则

- 沿用 V1 暖色主色、白色卡片、轻灰底；页面标题/工具栏/输入框/按钮/空态统一，减少大横幅和重复嵌套卡片。
- 列表页重效率、创建页重清晰、任务页重进度和行动、阅读页重可用空间。合同修改在首页优先，但三业务地位并列。
- 导航高亮父业务；面包屑展示业务/任务/文件；深链携带真实对象标识。刷新、前进后退、返回列表保留筛选与页码，未保存编辑有保护。
- 全局聚合不能在浏览器拼三个有限列表后冒称全量；现有生成列表有 limit、比对接口形态也不同，需明确新增 owner-scoped 聚合查询或可靠全量分页方案，统一全局搜索、分页与任务指标。
- 三业务保留独立处理/交付/审核状态，统一仅做展示映射；失败、覆盖不足、待审阅和无可下载文件不被“完成”一词掩盖。
