## 1. 现状链路与信息分布（摸底）

### 1.1 V1（生产主形态，`compare.html + compare.js`，hash 路由 `#compare?mode=list|new|detail&id&pair`）

| 层级 | 容器 | 放了什么 |
| --- | --- | --- |
| 任务列表 | `#view-compare[data-mode=list]` | 搜索框、状态下拉、刷新、新建按钮；表格（任务/合同组/状态/差异/查看）；分页 |
| 新建 | `#compare-create` 卡片（mode=new） | 标题+「1 / 2 · 准备文件」步骤文案、任务名输入、A/B 文件夹配对（按钮+说明小字）、逐组左右文件卡、「添加一组」「开始上传并对比」「继续上传」、上传消息行 |
| 任务详情 | `#compare-detail` 卡片（mode=detail） | H1 任务名、`状态 · N 组`、`compare-direction-note`（→ 图标 +「差异统计方向 合同A→合同B」+ 解释小字）、处理中提示小字、「合同组」标题+组列表（序号/名称/A文件名/B文件名/状态·差异数/错误） |
| 结果查看 | `#compare-viewer` **全屏 dialog**（叠在详情页上，含 backdrop + Esc + ×关闭 + 上一组/下一组） | 工具条：组标题、组导航、×关闭；摘要行：「当前结果 共N处差异·修改/新增/删除」+ 覆盖不完整 chip；第二工具条：Word视图/双栏对照切换、**「N 处修订」重复计数**、「显示源文档」勾选、痕迹下拉 |
| 修订列表（rail） | `.compare-word-revisions`（可拖宽） | 「N 处修订」**第三处计数**、上一处/下一处+「x / N」、类型筛选、修订项列表（每项 136px 高卡：序号/类型/摘要/**采用A/采用B radio**） |
| 文档区 | Word 视图：合并栏+源文档双栏（各自可拖宽）；双栏对照：左右两栏+可拖分隔+SVG 连线 | 正文、diff 高亮、连线（仅对照视图） |
| 人工选择 | `.compare-selection-panel`（结果区底部横条） | 进度文本、状态文本、问题文本、**6 个按钮**（全部A/全部B/定位待选择/保存/预览可生成性/生成）、生成后下载区（4 个下载按钮） |

### 1.2 V2（`src/pages/Compare/ComparePage.tsx`，路由 `/compare`）

**单页纵向无限堆叠**：任务表 → 新建卡片 → 任务详情卡（含同款 direction-note）→ viewer 卡（`role=dialog` 但 inline 堆在详情卡下方）。与 V1 信息架构不一致，无独立路由层级。

### 1.3 现状问题（用户视角）

1. **详情页套 dialog 两层壳**：`compare-detail` 自己几乎没信息（名字+状态+方向说明+组列表），点开组再弹全屏 dialog；「关闭/上一组/Esc」三套退出语汇，深链状态与 dialog 开闭耦合易错。
2. **方向说明整段属于「解释性废话小字」**（三禁令 2）：「差异统计方向 合同A→合同B / 新增删除均按此方向解释」——方向在结果工具条一处即可表达。
3. **三处修订计数重复**（摘要行 / Word 工具条 / rail 标题）。
4. **选择面板信息过载**：进度+状态+问题三行文本 + 6 按钮 + 下载区；「预览可生成性」是暴露给用户的技术概念（生成点击后服务端本来就会校验）。
5. **修订列表实际可视高度极低**（`.compare-diff-list` `max-height:220px`），与文档区域高度不匹配——「详情页布局感觉不太好」的直接体感来源之一；136px 高项里 radio 与底部面板的全量操作语义重复。
6. **V2 无页面划分**：列表/新建/详情/结果全在一个滚动页里，且结果查看器与 V1 结构分叉。

## 2. 重设计方案

### 2.1 页面划分（信息架构）

```
比对任务列表 ──┬── 新建比对（独立 mode/page，上传即建任务）
              └── 比对工作台（任务页：详情 + 合同组 + 结果 + 选择 + 导出 合一）
```

两级嵌套，取消 dialog 层。「各页面放什么」：

**P1 比对任务列表**：任务名、组数、状态、差异数、查看入口、搜索/状态筛选、新建按钮。（现状基本健康，仅随全站列表统一令牌照搬，不另改。）

**P2 新建比对**：任务名、A/B 文件夹一键配对（保留，核心效率功能）、逐组文件卡、提交与断点续传。
- 删：「1 / 2 · 准备文件」步骤文案（三步说明小字）；配对说明缩为按钮旁一句短注。
- 上传中/失败消息保留一行内联。

**P3 比对工作台（合并 detail + viewer，废弃 dialog）**：

```
┌ 页头：任务名 ｜ 状态·N组 ｜ (处理中:进度一句话)
├ 合同组切换条：chip[序号 组名·差异数·状态点] …(横向滚动)     ← 取代组列表+上一组/下一组
├ 结果工具条(一行)：[Word视图|双栏对照] 痕迹▾ 显示源文档▢ ｜ A→B 共N处·改M·增I·删D ｜ ⚠覆盖不完整(可点)
├ 主区（整高 calc(100vh - 页头)）：
│   ├ 修订 rail（默认 320px，可拖宽，复用 FundLexColumnSplitter）
│   │   ├ 头部：上一处/下一处 + x/N ｜ 类型筛选
│   │   ├ 列表（与文档区同高，各自滚动；项高压缩：序号/类型/摘要/采用A·B）
│   │   └ 底部 sticky 选择条：已选 x/N ｜全用A 全用B｜ 保存 ｜ 生成选择结果(primary)
│   └ 文档区：Word 视图（合并+可选源文档）/ 双栏对照（含连线、可拖分隔）
└ （生成后）选择条内链出下载行：最终 DOCX｜带修订痕迹 DOCX｜报告 MD｜报告 JSON · vN
```

**合同组失败的组**：chip 上红状态点，选中后结果区显示失败原因+（可重试提示），不再进结果视图。

**任务处理中**：主区显示「处理中/等待上传」空态+配对核对（沿用 pair 状态行内嵌 chip 条，不单独一卡）。

### 2.2 删除/归并清单（三禁令对照）

| 现状 | 处置 | 依据 |
| --- | --- | --- |
| `compare-direction-note` 整卡（含解释小字） | **删**；方向以工具条 `A→B` 前缀表达 | 三禁令2（解释性小字）+3（该删不藏） |
| 「上一组/下一组/×关闭」+backdrop+Esc | **删**；组切换=chip 点选，退出=列表面包屑/浏览器后退 | 重构优先：取消 dialog 层 |
| Word 工具条「N 处修订」重复计数 | **删**；计数只留摘要行 | 三禁令1 |
| 「预览可生成性」按钮 | **删**；点「生成选择结果」即校验，阻塞原因内联显示在选择条 | 技术概念不外泄 |
| 底部 `.compare-selection-panel` 横条 | **拆**：进度+操作并入 rail 底部 sticky 条；下载并入生成后的选择条第二行；状态/问题变内联短句 | 信息归位：选择与修订列表同域 |
| `compare-pending-note` 小字 | 并入处理中空态 | 三禁令2 |
| V2 单页堆叠 | 拆 `/compare`、`/compare/new`、`/compare/:taskId?pair=` 三路由，结构与 P1/P2/P3 对齐 | 页面划分+两端一致 |

### 2.3 布局规格（P3 主区）

- 结果区整高 `calc(100vh - 页头高度)`，rail 与文档区同高独立滚动（修掉 `max-height:220px`）。
- rail 宽度沿用 `fundlex-compare-revisions-width` 持久化 + 分隔条（复用 `FundLexColumnSplitter`，令牌内拖拽态）。
- 修订项卡片压缩：序号 28px 列+类型 chip+摘要一行截断+`采用A/采用B` 同行右置；目标项高 ~64px（现为 136px）。
- 双栏对照连线、gutter、splitter 行为不变（工单 A 已性能重构）。
- 小屏（≤760px）：沿用 mobile-pane 切换现状；chip 条横向滚动。
- **令牌**：全部过渡/控件/列表态仅引 `DESIGN_TOKENS_20261101.md` 既有令牌，无新增色值；动效仅复用既有 opacity/transform 微动效（项激活态背景 `--dur-fast`）。

### 2.4 兼容与迁移

- hash 路由 `mode=list|new|detail&id&pair` 全部保留（深链不碎）；`viewerOpen` 状态废除。
- localStorage 键（split 比、视图模式、源文档、痕迹）不动。
- a11y：dialog→`role=region` + `aria-labelledby`；chip 条 `role=tablist`。
- 浏览器测试选择器更新：`#compare-viewer.hidden`、`#compare-close-viewer`、backdrop 等引用随测随改（本线已有 `tests/browser` 比对套件需适配）。
