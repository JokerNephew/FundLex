# EN2 · C 类用户决策项（1 件，转呈用户）

## FL-D937(7)：模型配置页的可选模型清单要不要按供应商现行目录更新？

**背景（事实层，已核实）**：
`fundlex/user_model_connections.py:20-35` 的 PROVIDERS 内置模型清单仍是旧代命名（moonshot-v1-8k/32k/128k、glm-4-flash 等），决定「模型配置」页下拉可选项；选不到的模型只能走 custom 手填（能绕过但麻烦）。审计环境无法联网核验各家现行目录，故无法替你列新清单。

**需要您拍板的问题（原文转呈）**：
1. 内置下拉的模型名单是否按各家供应商现行目录更新？
2. 若更新，准入口径是什么——只列各家当前旗舰/主推对话模型（建议），还是全量列可对话模型（清单会很长）？
3. 供应商范围是否只维持现有几家（月之暗面/智谱等现有项），还是要新增供应商（如新增，需您点名对象）？

**为什么归您**：下拉名单是产品呈现决策（选什么给用户看、把哪些模型摆到默认视野），不是技术对错；代码侧任意一版清单都能跑通，custom 通道已是兜底。

**施工承诺**：您拍板后到数据回填为止只需常规验证（内置项连通性走既有的 test_connection 真测路径）。
