# FundLex 正式交付计划与进度

日期：2026-10-13。口径：本计划是"正式交付版本"的实施与验收计划；执行状态实时更新（`[x]` 完成 / `[ ]` 未完成）。与 `IMPLEMENTATION_PLAN.md` 的分工：本文件只记录正式交付范围、阶段、验收与进度；历史与运行记录仍在实施计划与结果文档中。

## 1. 交付定义

**软件发布版（本计划目标）**：一套可部署、可操作的合同修订应用——任务工作台支持"只读诊断"与"合同修订（评测）"两种处理模式；修订产物按执行模式持久化、按权限下载；正式写入只有在规则包离线发布批准（不可伪造）存在时才会开启，代码强制校验。修订支持 6 个 action；其余 action 与结构边界按设计失败关闭并如实报告。

**明确不在本计划内**（外部条件）：业务专家的独立真值/离线发布批准、生产 OIDC/数据库/对象存储/容量、模型固定版本、正式自动写入的开启。这些未满足前，正式动作保持关闭，这不是软件缺陷而是发布门槛。
