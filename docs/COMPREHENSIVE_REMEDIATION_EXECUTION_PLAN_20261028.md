## 开工前澄清与统一决定

- 依据综合审查、指引原件和已确认裁定：规则实际授权范围内完整修改，范围外不润色/去重/新增；实际正文摘要对应目标均盘点。当前无需要再向用户确认的业务授权问题。
- 每位开发agent先读AGENTS、集中问题对应条目、审查报告/反例并核对归属；有接口或设计疑问先向主agent列明，主agent按本契约裁定后再写相关实现。不向用户转嫁工程选择。不得以“不提问”为由掩盖凭据/服务故障或伪造验收。
- 默认采取严格公共参数allowlist、服务端transport配置、版本不可变产物、全写入fencing、统一下载与交付裁决；未知证据不判通过。人工编辑指引是草稿，不自动拥有机器资格。
- 模型账本只观测。费用/次数cap不得暂停；上下文/输出容量、并发/限流、磁盘/文件安全、有限技术重试和无进展防循环保留。供应商真实鉴权/余额故障如实恢复，不冒称用户预算限制。
- Compare文本优先/左版式为基底保持；格式/结构未比较明确提示，numId冲突必须明确重映射/采用左定义或失败关闭，不静默误绑定。
- 现有外方修订保留并明确列清单；我们修订以manifest与来源辨别而非仅author名；不支持结构入口诚实拒绝，已支持普通同段修订必须可写/Review可用。真实Word/WPS无环境时不宣称往返验证。
