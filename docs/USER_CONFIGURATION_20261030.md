## 修改指引 → 我的指引

沿用现有“修改指引”入口，不新增一级页面。当前指引、本人上传版本、上传新指引
集中在此；可启用解析完成的版本或恢复内置指引。任务页不新增指引选择器。

点击版本的“规则组”进入规则详情，勾选/取消启用，点击“保存启停”。

- 配置按“本人 + 精确指引版本”保存，不改变其他人的内置指引。
- 至少保留一条规则；规则内容及其认证/hash不被开关修改。
- 保存仅影响之后创建的任务。补传、暂停恢复、已有任务沿用原快照。
- 关闭的规则不执行；JSON、Markdown报告和例外面板明确展示关闭项。
- 其余启用规则全部通过后为“交付完成（含例外）”，不是全指引的无例外完成；
  若启用规则失败，原有不完整/工作文件门禁继续生效。

## 设置 → 模型配置

普通成员可以维护自己的主模型和复核模型选择，或恢复系统默认。

- 模型名称必须由部署的服务商支持；不会因为保存而自动调用付费模型。
- 支持超时、输出token、上下文字符数、有限技术重试、受控reasoning选项。
- 不向用户开放服务地址、密钥值、密钥环境变量名、请求头或修改共享进程环境。
  因而个人设置不能把系统凭据转发到另一个地址。
- 本轮仅接入“合同修改”的新任务；指引解析、法规指引生成仍用系统模型。
- 创建任务时保存个人选项快照；后续修改个人设置不会更改已创建任务。
  部署端服务配置和凭据轮换仍由系统管理，不作为用户快照秘密存储。
- 页面不保证用户输入的模型必然在供应商可用；鉴权/可用性需真实任务验证，
  错误按既有暂停/失败契约展示，不降级冒充成功。
